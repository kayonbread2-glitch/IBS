# Presentation tools
These tools provide a comprehensive platform to create our super unique never been done before story telling stuffs.

# Prerequisites
Install go lang tools from da google.

https://go.dev/

Download zip of project from this github page and unzip.

# Server startup
Run editor.bat and allow access when prompted.

# Server usage
Open a browser and navigate to `localhost:8080/website/?q=test`

you may replace `test` with the name of any `.md` file in the `markdown` folder.

Make sure to check `disable cache` in the network tab of browser tools (ctrl + shift + i) or refreshing the page may not reload the changes you have made to the markdown.

View the `test.md` file in the `markdown` folder for sample usage
